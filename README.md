# Thesis-2023
The repository for the master thesis of Automated Essay Scoring


## How to run
- Folder structure:
    
    1. `src/data`: containing data
    2. `src/dataset`: dataset loader definition
    3. `src/models`: containing models definition
    

- Prepare dataset:
    ```bash
    bash scripts/run_prepare_ASAP_data.sh
    ```

- Training:
    ```bash
    bash scripts/run_traint_CTS.sh
    ```
